# BrainOS SVG icon pack

The pack is generated by `tools/generate-icons.ps1` into `qml/assets/icons/`.

- Canvas: 24×24
- Stroke: 1.8 px
- Caps and joins: rounded
- Default foreground: `#F4F5FA`
- Optical padding: approximately 3 px
- Application presentation: monochrome glyph inside a wallpaper-aware colored container
- System presentation: monochrome glyph without decorative gradients

The 54 icons cover applications, places, navigation, editing, media, window controls,
connectivity, power, storage, hardware metrics, and unavailable-service states.
